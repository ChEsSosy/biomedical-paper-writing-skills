# Distribution attribution policy

This directory distributes six general biomedical-writing Skills maintained by ChEsSosy. Read ATTRIBUTION.md for project credits, reference-project notices and the current license status.

Keep software attribution separate from the user's scholarly content. Do not insert ChEsSosy, this tool's name, a repository URL, copyright notices, watermarks, promotional text, acknowledgements or a tool citation into manuscripts, abstracts, captions, tables, slides or other user deliverables merely because these Skills were used. Do not add these notices to prose or QC outputs automatically.

Preserve genuine scientific citations and existing author-approved content. If the user explicitly requests a tool acknowledgement, handle it separately. Journal or institutional AI-use disclosure requirements remain the user's responsibility and are not waived by this attribution policy.

Do not edit hash-bound module payloads solely to add attribution. Distribution notices live at this suite root; the six module directories and their inventories remain the source baseline.
