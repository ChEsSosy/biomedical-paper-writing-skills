# Article and Target Profile Usage

An M01 Article profile remains derived from the user's currently admitted reference corpus; this Skill does not contain a fixed scientific writing persona. If the user supplies a different homogeneous Article corpus, M01 may distill a different descriptive profile and M03 can consume its reviewed identity.

Use only aggregate communication features actually present with support in the admitted profile. Current deterministic M01 outputs include sentence/paragraph-length distributions, observable section structure, explicit hedge/transition marker rates, and citation/Figure-reference positions. Its conservative passive-construction marker is not a grammatical voice percentage; it does not supply clause-density or section-level rhetorical-role annotations. Do not attribute those capabilities to the deterministic profile or invent a feature ID for an editorial judgment.

Bind a `profile_alignment` change to the exact profile ID, version/hash, feature ID, and support reference. The profile must be supplied separately as an `author_approved` Original Article `style_profile` or `structure_profile`; the operation must reference it in `upstream_artifact_refs`. Use a strict JSON Pointer such as `/feature_support/<feature-id>` or `/sections/<section>/feature_support/<feature-id>` for `feature_support_ref`; the resolved support object's `feature_id` must match exactly. Keep separately supplied model-assisted observations and editorial judgments identifiable as such; they do not become admitted profile features by being mentioned in a writing guide.

Never copy recognizable phrases, n-grams, paper-specific framing, claims, mechanisms, conclusions, novelty, topic priorities, or an individual author's worldview. Weak or missing profile evidence falls back to clear biomedical academic prose. A target-journal profile must be supplied or separately verified for the actual target and remains formatting/communication guidance, not scientific authority.
